# PARAMETER_REFERENCE — 參數、單位、預設值、公式對照

**標籤說明**

- 【真】真實工藝參數
- 【理】理論計算參數

**現況欄說明**：✓ 已有、△ 部分、✗ 無。

**聲明**：本系統是視覺模擬，不能取代實際打樣或色彩管理。
