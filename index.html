檔案

文字若未轉外框，會以系統已安裝字型顯示；交付打樣前建議在 Illustrator／Affinity 先「建立外框」再上傳。

快速指派到目前圖層

依 SVG 內偵測到的填色／描邊顏色。點一下 → 該顏色的所有元素指派到目前圖層；再點一下取消。載入時預設：相同顏色 → 相同效果。

依 SVG 圖層

Illustrator／Affinity 的圖層在 SVG 裡是有名字的 <g>。點一下 → 整個圖層指派到目前圖層。

效果圖層

圖層由上往下 = 印刷順序由下往上（列表最下方最先印）。同一元素若被多個圖層指派，以最接近的群組指派為準。

SVG 群組結構

點一個群組 → 整組指派到目前圖層。右側圓點是該節點目前的效果（淡色 = 從上層群組繼承）。

燙印打樣室 Foil Proof Lab

在瀏覽器裡把 SVG 設計稿模擬成燙銀、燙金、燙紅、專色油墨、局部上光與打凹打凸的紙本打樣，並可平鋪多張匯出社群尺寸 mockup。
