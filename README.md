# 燙印打樣室 · Foil Proof Lab

**線上使用：https://naldo-w.github.io/foil-proof-lab/**

在瀏覽器裡把 SVG 設計稿模擬成紙本印刷打樣：16 色燙箔、雷射箔（線條／彩虹／亮粉／星空／碎冰／珍珠／透明膜）、油墨、12 色專色、6 色螢光、發泡印花、植絨、亮面／霧面／磨砂／立體／亮粉 UV、打凹／打凸，
再平鋪多張、換視角，匯出 IG／FB 尺寸的 mockup PNG。純前端單一 HTML，不需要安裝、不需要伺服器。

## 功能

- **上傳 SVG**（拖放或選檔），自動偵測顏色：預設「相同顏色 → 相同效果」，滿版底色矩形自動當成紙色
- **指派方式**：依顏色、依 SVG 圖層（具名 `<g>`）、結構樹
- **檢視**：滾輪縮放（以游標為中心）、拖曳平移、100%／填滿／＋－按鈕
- **紙張**：15 種紙質（銅版、雪銅、珠光、象牙卡、蛋殼紋、水彩紙、雲彩紙、萊妮、條紋、麻布、皮紋、鎚目、牛皮、再生、毛氈），紋理以 feTurbulence 高度圖＋feDiffuseLighting 打光生成；可調紋理強度、凹凸深度、顆粒、尺寸、光源角度、混合模式、光澤
- **每個圖層 = 工法 + 顏色 + 疊加加工**：工法有燙箔、燙雷射（7 種）、印刷（平版／數位）、凸版印刷、網版印刷、不上色（只做加工）、不印；顏色有常用色票（16 色箔、油墨、12 專色、6 螢光）與自訂色；加工可疊加：打凸／打凹、亮面／霧面／磨砂／立體／亮粉 UV、發泡、植絨——例如「印刷 + 打凸 + 亮面 UV」
- **分版／挖空**：多層燙箔或油墨重疊時，下層沿上層圖形外擴「安全空間」後挖空（可全域調整、可逐層關閉）
- **匯出 SVG（分版）**：每個效果一個具名 `<g>`（由下而上 = 印刷順序），挖空以 `<mask>` 實作，附紙色資訊
- **版面 Mockup**：1080×1080 / 1080×1350 / 1080×1440 / 1080×1920 / 16:9 / A4 或自訂；
  單張、整齊、錯開、隨機、扇形、階梯六種鋪法；正上方／俯 30°／俯 45°／左右前 45°／等角等視角；
  光場預設「合併」：同一效果圖層在整個版面只做一張遮罩（symbol + use），一盞燈的反光帶連續掃過所有卡，交疊處以遮擋遮罩處理；亦可切「各卡獨立」。光源是真 3D 模型：燈為桌面上方一點（落點可拖曳、Z 為高度）、相機在透視原點，鏡面高光落在「相機 → 燈的鏡像」與桌面的交點，光斑與投影以落點為準，任何俯角／方位／整體旋轉都成立；可調強度、大小；背景反光可關（消光桌面）；卡片離地高度影響投影距離與軟硬；每張卡片各自反光與投影；整體旋轉；**卡片版本混搭**：把不同效果組合存成版本 A／B／C，版面上的卡片依序輪流或隨機套用
- **預覽背景**：深灰／白底／黑底；滑桿數字雙擊可直接輸入
- **匯出 PNG**（1× / 2×），設定自動存在瀏覽器 localStorage

## 原理

每個效果圖層是一個 `div`：箔面漸層 + 全息 + glare 多層 `mix-blend-mode`，
再用「只保留該圖層元素、全部填白」的 SVG 當 CSS `mask-image`，所以任何路徑、文字、描邊都能套用。

## 建議

- 文字請先在 Illustrator／Affinity **建立外框**再上傳，否則會以系統字型顯示
- 匯出請用 Chrome／Edge；Safari 對 `foreignObject` + `mask` 支援不完整
- 畫面效果為視覺近似，實際成品以印刷廠打樣為準
