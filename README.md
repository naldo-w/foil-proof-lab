# 燙印打樣室 · Foil Proof Lab

**線上使用：https://naldo-w.github.io/foil-proof-lab/**

在瀏覽器裡把 SVG 設計稿模擬成紙本印刷打樣：16 色燙箔、雷射箔（線條／彩虹／亮粉／星空／碎冰／珍珠／透明膜）、油墨、12 色專色、6 色螢光、發泡印花、植絨、亮面／霧面／磨砂／立體／亮粉 UV、打凹／打凸，
再平鋪多張、換視角，匯出 IG／FB 尺寸的 mockup PNG。純前端單一 HTML，不需要安裝、不需要伺服器。

## 功能

- **上傳 SVG**（拖放或選檔），自動偵測顏色：預設「相同顏色 → 相同效果」，滿版底色矩形自動當成紙色
- **多份 SVG**：「＋ 加入 SVG」或拖放多個檔案同時載入（正面／背面、A／B 稿），各自有指派、效果與版本；版面可設定順序（↑↓）、勾選參與，分配方式有依序輪流、隨機、逐列／逐欄輪流、左右／上下對照，「並排比較」一鍵各放一張排成一列；不同比例的 SVG 各依自己的 viewBox 顯示
- **指派方式**：依顏色、依 SVG 圖層（具名 `<g>`）、結構樹
- **依圖層名稱自動套用**：上傳時先讀 SVG 圖層（`<g id>`）名稱，符合「工法 · 顏色 + 加工」規律的圖層直接建立對應效果，其餘元素再依顏色歸類。範例：`燙箔 · 金`、`燙雷射 · 彩虹`、`凸版 · 185C + 打凸`、`網版 · 白墨 + 發泡`、`印刷 · #e4002b（金屬墨）`、`加工 · 打凹`、`不印`；也接受簡寫與英文（`燙金`、`燙紅打凹`、`foil-gold`、`holo cosmos`、`ink white puff`）；紙張群組 `紙 · 新百代 #141414`、`紙張 · 黑卡`、`象牙卡` 會直接設定紙質與紙色
- **檢視**：滾輪縮放（以游標為中心）、拖曳平移、100%／填滿／＋－按鈕
- **紙張**：23 種紙質（銅版、雪銅、珠光、象牙卡、蛋殼紋、水彩紙、雲彩紙、萊妮、條紋、麻布、皮紋、鎚目、牛皮、再生、毛氈，以及台灣常用的新百代、啤酒紙、星幻、剛古、環保道林、荷蘭板、象牙卡），紋理以 feTurbulence 高度圖＋feDiffuseLighting 打光生成；可調紋理強度、凹凸深度、顆粒、尺寸、光源角度、混合模式、光澤
- **每個圖層 = 工法 + 顏色 + 疊加加工**（工法與加工以小方塊即時預覽選取）：工法有燙箔、燙雷射（13 種，含 pokemon-cards-css 的 holo／reverse／radiant／rainbow／amazing／secret／trainer／shiny）、印刷（平版／數位）、凸版印刷、網版印刷、不上色（只做加工）、不印；顏色有常用色票（16 色箔、油墨、12 專色、6 螢光）與自訂色；加工可疊加：打凸／打凹、亮面／霧面／磨砂／立體／亮粉 UV、發泡、植絨——例如「印刷 + 打凸 + 亮面 UV」
- **油墨細節**：溢出（外擴＋邊緣暈開）、不平均（斑駁）、雙色漸層（水平／垂直）；網版可選目數 80–300 目（網紋與墨層厚度跟著變）；凸版壓印的陰影／受光邊會依紙色深淺自動調整
- **分版／挖空**：多層燙箔或油墨重疊時，下層沿上層圖形外擴「安全空間」後挖空（可全域調整、可逐層關閉）
- **兩個工作模式**：頂列切換「卡片」（紙張／效果／結構）與「場景」（排列／相機／燈與桌面／鏡頭）；檔案 chips、復原／重做（⌘Z）、參數、分享、匯出都在頂列；畫布底部浮動工具列（縮放、背景、翻面／品質、🎲）
- **打凸／打凹**：以 SVG feDiffuseLighting 對圖形的模糊 alpha（高度圖）打光，得到真正的斜面明暗，整層以 hard-light 疊在紙與油墨上（深色紙也看得到受光邊）；光向跟滑鼠／燈走；匯出時把打光結果烘成 PNG。**紙厚與透印**（紙張分頁）：紙厚 mm 決定透到另一面的門檻（紙厚 × 3）與另一面輪廓模糊；光影強度、另一面強度可調
- **翻面與另一面效果**：卡片模式點卡片或按「翻面」看背面（有連結的正反面就顯示另一份，沒有就是同一張紙的空白背面）；壓過 1px 的燙箔壓痕、凸版、打凹在另一面以鏡射的浮凸呈現，打凸／發泡則反過來變凹，場景裡的正反面也一樣
- **鏡頭清單**：把排列＋相機（可含燈光桌面）存成鏡頭，多個鏡頭「全部匯出」依序渲染打包 ZIP
- **效果樣本卡**：⋯ 選單「效果樣本卡（44 格）」載入 A6 橫式樣本卡（燙箔 16、燙雷射 13、油墨 8、表面處理 7），每格點一下可複製效果，切到自己的檔案後在效果圖層「貼上效果」；由 `tools/make_swatch.py` 產生 `swatch-card.svg`
- **分享網址**：參數 gzip 壓進 `#p=`，開啟即載入；以 .json 下載為主；網址只適合小檔（≤ 8KB），8–60KB 會提示通訊軟體可能截斷，>60KB 停用；.json 可直接拖進畫布載入；可勾「只分享卡片互動預覽」給對方一個只有互動、預覽與環境（縮放、背景、翻面）、沒有編輯的檢視頁；**參數 JSON** 匯出／匯入可勾選項目
- **刀模**：圖層命名 `刀模`／`die-cut`／`刀線` 的外框路徑會裁切卡片（clip-path），影子、場景遮擋、匯出都跟著外形
- **桌面照片**：上傳實拍桌面當背景，可調尺寸／位移／旋轉；**接觸陰影**：交疊處的環境光遮蔽
- **空中灑落**：瀑布式由上而下沿直線落下，左右散開、隨機 3 軸旋轉、部分懸空
- **匯出**：透視與景深在 Worker + OffscreenCanvas 裡算（不支援時退回主執行緒）
- **光源**：單一主燈固定在桌面 3D 空間（位置、高度、照向目標），畫布上的 gizmo 可拖燈球、▲▼ 高度、目標十字；改視角時燈不動，反光區由真實鏡面幾何算出；聚光錐、柔光、色溫、大小；背光與傾斜的卡自動變暗
- **3 軸旋轉**：每張卡 X／Y／Z 旋轉以正交投影落成仿射矩陣，合併光場、遮罩、匯出照常；所有鋪法有「自然微傾」；隨機鋪滿與扇形可設 X／Y 軸；新鋪法「空中灑落」（散布、傾斜、懸空比例與高度）；「鋪磚」可調錯開 %；扇形可調圓心；隨機鋪滿只鋪在相機看得到的範圍（含出血）且避免同位置堆疊；排列可「重設數值」（鋪法不變）
- **正反面**：加入尺寸相同的 SVG 時詢問是否連結為正反面；連結後由「翻面比例」決定哪些卡翻到背面，依序／逐列／逐欄輪流時正反交替，「並排比較」正反各一
- **參數 JSON**：頂端「參數」可勾選匯出／匯入紙張、效果圖層＋指派、版面、光源與背景、版本、檔案（含 SVG 原文）
- **效能**：變更以 rAF 合併、存檔防抖；拖曳滑桿期間自動線框、放開後完整重建；超過 60 張自動線框；遮罩快取 LRU 並釋放 blob
- **場景**：預覽品質有線框（只畫外框與編號）／快速／完整；隨機鋪滿可指定張數；扇形以直徑、起點、終點角度定義弧線並可顯示虛線路徑；視角含 X／Y 位移；鏡頭有焦段（35mm 等效）、點畫布對焦、光圈景深（匯出時 WebGL 逐像素計算）、曝光；桌面材質：素色／霧面／亮面／木材（深淺快選）／石材（石塊、碎石、大理石）／布／皮革，反光可關閉、可調光斑與光澤。
- **版面尺寸**：1080×1080 / 1080×1350 / 1080×1440 / 1080×1920 / 16:9 / A4 或自訂；
  單張、整齊、錯開、隨機、扇形、階梯六種鋪法；正上方／俯 30°／俯 45°／左右前 45°／等角等視角；
  合併光場：同一效果圖層在整個版面只做一張遮罩，一盞燈的反光帶連續掃過所有卡，交疊處以遮擋遮罩處理（壓痕與投影也不會穿到上面的卡）。光源是真 3D 模型：燈 → 焦點 → 反光區 → 視角以鏡面幾何綁定（拖焦點決定反光位置，燈自動移到能反射進相機的地方；拖燈則反推焦點；Z 為高度）；壓痕／打凸／打凹的明暗方向跟著燈走、相機在透視原點，鏡面高光落在「相機 → 燈的鏡像」與桌面的交點，光斑與投影以落點為準，任何俯角／方位／整體旋轉都成立；可調強度、聚焦、柔光、色溫（2200–9500K，或自訂色）、大小；背景反光可關（消光桌面）；卡片離地高度影響投影距離與軟硬；每張卡片各自反光與投影；整體旋轉；**卡片版本混搭**：把不同效果組合存成版本 A／B／C，版面上的卡片依序輪流或隨機套用
- **預覽背景**：深灰／白底／黑底；滑桿數字雙擊可直接輸入；每個可調項目旁有 (i) 說明
- **匯出 PNG**（1× / 2×）：匯出前把向量遮罩點陣化成 PNG、隱藏圖形剔除，張數再多也不會撞到 data: URL 上限；版面預覽預設「快速」（略過壓痕／挖空／紙紋），匯出時自動切完整
- 設定自動存在瀏覽器 localStorage

## 開發

單一模板 `foil-proof.template.html` 以 `__SAMPLE_SVG__ / __SAMPLE_NAME__ / __SAMPLE_CREDIT__ / __SOURCE_LINK__` 佔位；`python3 tools/build.py` 產出 `index.html`，加上參數可另外產出內嵌私人設計稿的版本（不進 repo）。

## 原理

每個效果圖層是一個 `div`：箔面漸層 + 全息 + glare 多層 `mix-blend-mode`，
再用「只保留該圖層元素、全部填白」的 SVG 當 CSS `mask-image`，所以任何路徑、文字、描邊都能套用。

## 建議

- 文字請先在 Illustrator／Affinity **建立外框**再上傳，否則會以系統字型顯示
- 匯出請用 Chrome／Edge；Safari 對 `foreignObject` + `mask` 支援不完整
- 畫面效果為視覺近似，實際成品以印刷廠打樣為準
